Usage Example: fontfile/characters/scale

font_to_arduino "fonts/bold_dot_digital-7.ttf" font.h "%*?,-.=+$#@:!|[]{}<>&0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ" 1.0

or just drag and drop a ttf/otf file onto the font_to_arduino.exe

NOTE: ALL font files are different, go here https://www.glyphrstudio.com/app/ and load your font into the online app, you can edit the font and see what glyphs are available.

Fonts can be downloaded from here:
https://www.dafont.com/
or here:
https://www.1001fonts.com/

After creating a font array, remember to edit the arduino sketch so each font gets the correct address.
